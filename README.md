# Простой веб-сайт обо мне + авторизацией

Простой проект со стартовым меню, страницами регистрации и входа, реализованный на чистом фронтенде без использования сторонних бэкенд-серверов.

##  Как запустить проект

1. Скачайте репозиторий на свое устройство
2. **Для начала работы откройте файл `start_page.html`** в любом веб-браузере.

## Особенности работы
* **Без сервера:** Все данные учетных записей (логины и пароли) **сохраняются в LocalStorage вашего веб-браузера**. 
* Проект полностью автономен и работает прямо с локального диска.
